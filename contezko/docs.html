Operational Runbook

Start the server (stunnel must be in PATH):
    bankserve > bankserve.log &

Status and shutdown:
    bankserve status
    bankserve kill

Client operations (bankshell), with $BANKOFEULER_HOME set:
    bankshell sync  -a ACCOUNT VALUE      make the shell aware of a value the server holds
    bankshell list  -a ACCOUNT            show all values in the account
    bankshell check -a ACCOUNT VALUE      ask the server whether a value exists
    bankshell split -a ACCOUNT VALUE PART split a value into PART and VALUE-PART
    bankshell merge -a ACCOUNT A B        merge two values into their sum
    bankshell randomize -a ACCOUNT VALUE  split a value into a valuable part and a worthless part

Values are written as "$10" (dollars) or as hexadecimal numbers.  $1 = 2^768.
After an unexpected failure, inspect the server log for incomplete splits and merges and reconcile.
